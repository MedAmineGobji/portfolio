# Portfolio — Mohamed Amine Gobji

Portfolio professionnel statique en HTML/CSS/JavaScript, conçu pour présenter mes projets, mes compétences et mes services freelance en français.

## Voir le site
Après activation de GitHub Pages, le site sera disponible à :
https://medaminegobji.github.io/portfolio/

## Publier avec GitHub Pages
1. Ouvrir **Settings** dans ce dépôt.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/(root)**, puis **Save**.
5. Attendre la fin du déploiement et ouvrir le lien affiché dans Pages.

## Personnalisation
- Modifier le fichier `index.html`.
- Mettre à jour les projets, les liens et les compétences selon les réalisations réelles.
- Ajouter des captures d'écran ou des démonstrations quand elles sont disponibles.
