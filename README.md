## Exécuter en local

Aucune installation ou compilation n'est nécessaire.

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/MedAmineGobji/portfolio.git
   ```
2. Ouvrez le dossier du projet.
3. Ouvrez `index.html` dans votre navigateur.

Pour un aperçu local avec un serveur HTTP, vous pouvez aussi lancer :

```bash
python -m http.server 8000
```

Puis ouvrez [http://localhost:8000](http://localhost:8000).

## Déploiement avec GitHub Pages

1. Ouvrez **Settings** dans le dépôt GitHub.
2. Sélectionnez **Pages** dans la barre latérale.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main` et le dossier `/(root)`.
5. Cliquez sur **Save**, puis attendez que GitHub termine le déploiement.

Une fois publié, le site devrait être accessible à l'adresse suivante :

`https://medaminegobji.github.io/portfolio/`
